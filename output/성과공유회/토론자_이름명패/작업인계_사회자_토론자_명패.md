# 사회자·토론자 테이블 배너 작업 인계

## 최종 확정 사항

- 규격: 가로 400mm x 세로 700mm, 4종
- 용도: 범어도서관 무대 토론 테이블 전면 부착용 무광 배너
- 공통 로고: 하단에는 `주민이 Green 고산` 로고만 사용
- 토론자 표기: 상단 `토론자`, 왼쪽 `성과확산`
- 사회자 표기: 상단 `사회자`, 왼쪽 `토론진행`
- 사회자 소속·직함: `청곡종합사회복지관 / 과장`
- 권장 소재: 무광 패브릭 또는 무광 합성지

## 최종 명단

1. 배영미 / 대구광역시환경교육센터 / 팀장
2. 전희택 / 제로웨이스트협동조합 세바퀴 / 대표
3. 허그림 / 숲과나눔재단 / 캠페이너
4. 이진규 / 청곡종합사회복지관 / 과장

## 현장 설치 기준

- 범어도서관 로고가 없는 테이블보의 무지 면을 객석 쪽으로 둔다.
- 테이블 폭이 180cm이면 배너 4장 160cm와 장당 약 4cm 간격으로 배치한다.
- 실제 착석 순서와 배너 순서를 반드시 일치시킨다.
- 상단 벨크로 2~3곳과 하단 보조 고정으로 말림을 방지한다.

## 재생성 방법

- 제작 스크립트: `tools/make_panelist_table_banners.py`
- 실행: `python3 tools/make_panelist_table_banners.py`
- 결과 폴더: `output/성과공유회/토론자_이름명패/`
- 4종 합본: `사회자_토론자_이름명패_4종_400x700mm_인쇄용_합본.pdf`

## 디자인 판단

- 검정에 가까운 짙은 테이블보와 아이보리·녹색 명패의 대비는 적절하다.
- 여러 기관 로고를 병렬 배치하지 않고 사업 로고 하나만 남겨 이름과 소속의 가독성을 우선했다.
- 토론자는 5~7분 의견 제시를 하더라도 독립 발표가 아니라 라운드테이블 참여이므로 `발표`가 아닌 `토론자`로 표기한다.
