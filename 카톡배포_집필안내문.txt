【 김연수 — 프롤로그 4p 】
[1~2p] 왜 종이팩인가
→ 국내 재활용률 수치부터 시작
→ 고산동 실태 수치 포함

[3~4p] 왜 주민인가
→ 리빙랩이란 무엇인가 (한 문단)
→ 주민환경연구원 모집 후 실제 벌어진 일
→ 주민 직접 발언 최소 1개 인용

⚠ 2차년도 사례보고서 p.5~6 참고
⚠ 설문 수치(p.37~42) 최소 2개 인용

【 김연수 — 에필로그 2p (800자) 】
→ "우리가 끝냈다"가 아니라
   "다음 사람에게 건넨다"는 톤
→ 감사 나열 금지
→ 마지막 문장이 기억에 남아야 함

----

【 이현직 — 1부 8p 】
[1~2p] 고산동은 어떤 동네인가
[3~4p] 주민환경연구원이 된다는 것
[5~6p] 동별 3가지 환경 문제
[7~8p] 왜 종이팩인가 — 선택의 근거

쓸 수 있는 수치:
- 모집: 47명 지원 → 20명 선발
- 발대식: 2023.9.12, 50명 참석
- 주민역량강화 18%↑ / 환경감수성 15%↑
- 팝업도서관 1,260명

⚠ 2차년도 보고서 p.8~14 참고
⚠ 고산1동·2동·3동 반드시 구분해서 쓸 것

----

【 김정현 — 2부 10p 】
[1~2p] 1→2차년도 전환
[3~5p] 아파트 / 카페 / 학교 모델 (각각 소제목)
[6~7p] 그린고산실천단 거버넌스
[8p] 노인 일자리 연결
[9~10p] MBC·TBN + 2차년도 성과

⚠ 2차년도 보고서 p.16~30 핵심 재료
⚠ 3가지 모델 반드시 별도 소제목으로 나눌 것
⚠ 컨소시엄 기관 이름 전부 명시

----

【 김정현 — 4부 12p 】
[1~2p] 시작 전 체크리스트
[3~4p] 1단계: 주민환경연구원 모집
[5~6p] 2단계: 수거 거점 구축
[7~8p] 3단계: 세척·집하·납품 구조
[9~10p] 4단계: 거버넌스 구축
[11~12p] 자주 막히는 지점 5가지 + 해결법

⚠ "소통을 강화하세요" 같은 추상 금지
⚠ "주 1회 카카오톡 단체방에 수거량 공지"처럼 구체적으로
⚠ 체크박스 형식 적극 활용

----

【 이승원 — 부록 4p 】
- 연도별 활동 일지 표
- 역대 주민환경연구원 명단 (이진규 과장 확인 후 기재)
- 컨소시엄 기관 목록 및 역할
- 주요 용어 설명
- 앱 QR코드

⚠ 서술형 금지, 표 형식으로만
⚠ 2차년도 보고서 전체에서 표·명단 발췌 활용
