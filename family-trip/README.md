# 엄마의 칠순, 안동 가족여행

2026년 11월 7~8일 · 9명 · 1박 2일 여행 준비 대시보드.

## 실행

```sh
npm install
npm run dev -- --port 3017
```

http://localhost:3017 에서 열고, `/report`에서 인쇄합니다.

환경변수가 없으면 현재 브라우저의 로컬 저장 모드로 동작합니다. 예산은 변경 저장 버튼으로 저장하고 준비 체크와 의견은 즉시 저장합니다. 다른 기기에는 동기화되지 않으며 브라우저 데이터를 지우면 저장 내용도 삭제됩니다.

공동 저장은 별도 Supabase 프로젝트와 family_trip_get / family_trip_save / family_trip_add_comment RPC 구현이 필요합니다. 현재 원격 저장 설정 및 배포는 완료되지 않았습니다. `.env.example`에는 변수 이름만 있습니다. 다른 업무용 프로젝트의 인증정보를 재사용하지 않습니다.

초기 일정과 금액은 기존에 작성된 초안입니다. 식당·체험 운영시간과 가격, 예약 여부는 재확인이 필요합니다.
