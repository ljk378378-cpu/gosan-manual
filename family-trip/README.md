# 안동 칠순 가족여행 웹앱

가족 암호 로그인 → 일정·예산·준비사항 공동 수정 → 의견 기록 → 칠순상 후보 선택 → 보고서 출력.

## 실행
`npm install`, `.env.example`을 기준으로 `.env.local` 설정, `npm run dev -- --port 3017`.

## 저장·접근
별도 Supabase 프로젝트를 사용합니다. 서버가 가족 암호를 확인한 뒤 7일 유효 HttpOnly 서명 쿠키를 발급합니다. DB는 고엔트로피 서버 전용 키를 요청 헤더로 검사하는 RLS로 보호합니다. 익명키 단독으로는 계획·의견에 접근할 수 없습니다. 클라이언트에는 서버 비밀키와 초기 여행자료가 포함되지 않습니다. 동시 편집 충돌은 revision으로 거절하여 덮어쓰기를 방지합니다.

모든 가족은 같은 수정 권한을 갖습니다. 최신 내용은 새로고침으로 불러옵니다. 예산은 변경 저장, 일정은 수정창의 반영 버튼으로 저장합니다. 공유 암호 재설정 시 SESSION_SECRET도 함께 교체해 기존 접속을 만료하세요.

## 배포
Vercel 프로젝트: andong-family-trip. 모든 환경변수는 서버 전용으로 설정합니다. 환경변수 변경 후 커밋·push로 재빌드합니다. 기존 로컬 브라우저 기록은 자동 업로드하지 않으며, 초기 공용 계획은 확인한 여행 초안으로 시작합니다.

## 출처
칠순상 사진은 각 업체의 상품페이지에서 가져온 비교용 이미지이며 사진 원본 링크와 출처는 화면에 표시합니다. 표시 가격은 2026-09-26 확인 기준이며 행사일 재고·배송/회수·옵션은 업체 확인이 필요합니다.
